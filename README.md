# EduTrade_by_Finovaters
# 📈 EduTrade– Finance Literacy Platform  

FinPlay.AI is an **AI-powered finance literacy platform** designed for **children and beginners** to learn the basics of **investing, trading, credit, and personal finance** through **gamified learning and paper trading**.  

The platform offers **real-time stock simulations, imaginary credit scoring, and interactive games**, providing a **risk-free and engaging environment** to understand financial concepts.  

---

## 🚀 Features  
 

### 💸 Paper Trading (with Futures & Options)  
- Virtual cash for **stocks, futures, and options trading**.  
- **Live market data** powered by Yahoo Finance API.  
- Real-time **portfolio tracking, PnL analysis, and margin usage**.  

### 🎮 Gamified Learning  
- Fun **quizzes, challenges, on saving, budgeting, investing.
- -**Discussion Forum
- **News made easy
- **Leaderboard & rewards** to encourage participation. 

### 🧠 AI & Analytics  
- Personalized learning path based on age and performance.  
- Real-time insights on trading strategies and risk behavior.  

---

## 🏗 Tech Stack  

- **Frontend:** React.js (Web) 
- **Backend:** Node.js with Express.js  
- **Database:** Firebase (User data, virtual portfolios, credit tracking)  
- **Market Data APIs:** Yahoo Finance API 
- **AI & Analytics:** Google AI APIs 
- **Security:** FireBase Authentication
